#  Real-Time Emotion Detection using OpenCV & TensorFlow

##  Overview
This project detects human faces in real-time using a webcam and predicts emotions such as Happy, Sad, Angry, etc., using a Convolutional Neural Network (CNN).

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## How it works
Camera → Face Detection → Preprocessing → CNN Model → Emotion Prediction

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## Tech Stack
- OpenCV (Face Detection)
- TensorFlow / Keras (Deep Learning Model)
- NumPy (Data Processing)
